Install

Install TalosBot

Two projects, one command each. Both commands below were run end to end in a clean, isolated environment on Linux before this page was published.

clud

Claude & Codex CLI but with safety 3rd and God Mode always.

curl -fsSL https://raw.githubusercontent.com/talos-hq/clud/main/install.sh | sh

What it does

  • Installs uv with Astral's official installer if it is not already on your PATH.
  • Runs uv tool install --force clud, which puts a single clud executable in uv's tool bin directory.
  • Runs a quick self-check on the installed binary, then runs uv tool update-shell so future shells find it. Set CLUD_NO_PATH=1 to skip editing your shell profile.

Prerequisites

  • A POSIX shell and curl. uv is installed for you if missing.

Pin a version

curl -fsSL https://raw.githubusercontent.com/talos-hq/clud/main/install.sh | CLUD_VERSION=2.8.47 sh

Check it with clud --version. Release catalog: manifest.json · source.

The agent

The agent that grows with you. talos-hq/hermes-slim is our fork of Hermes Agent by Nous Research. It runs from a git checkout.

git clone https://github.com/talos-hq/hermes-slim && cd hermes-slim && source ./activate

What it does

  • Clones the fork, then source ./activate runs the repo's own setup: it stages a pinned uv, installs Python 3.14 and the locked dependencies (hash-checked against uv.lock), and downloads bundled tools.
  • Activates the environment in your current shell and makes hermes available while you are inside the checkout. Run deactivate to undo it.

Prerequisites

  • git and bash or zsh. Fish and PowerShell use activate.fish and activate.ps1.
  • Disk space and time: first setup downloaded about 2 GB and took around 20 minutes in our test.

The fork's README links the upstream installer at hermes-agent.nousresearch.com. That installs upstream Hermes Agent, not this fork. uv tool install from the git URL is also refused by the fork's build on purpose. Use the command above.

Pin a version

git clone https://github.com/talos-hq/hermes-slim && cd hermes-slim && git checkout d4f228ac265af37d1a52ff65b28d884fd4b1aa22 && source ./activate

Pin by commit. Check it with hermes --version.
