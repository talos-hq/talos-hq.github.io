THE AGENT

The agent that grows with you. Our fork of Hermes Agent by Nous Research, with our fixes on top and upstream merged in.

talos-hq/hermes-slim

git clone https://github.com/talos-hq/hermes-slim && cd hermes-slim && source ./activate

What it does

  • Clones the fork. source ./activate then runs the repo's own setup: a pinned uv, Python 3.14, and the locked dependencies, hash-checked against uv.lock.
  • Activates the environment in your shell and puts hermes on your PATH while you are in the checkout. deactivate undoes it.

Prerequisites

  • git, and bash or zsh. Fish and PowerShell use activate.fish and activate.ps1.
  • Time and disk space: our first setup downloaded about 2 GB and took around 20 minutes.

Pin a version

git clone https://github.com/talos-hq/hermes-slim && cd hermes-slim && git checkout d4f228ac265af37d1a52ff65b28d884fd4b1aa22 && source ./activate

Pin by commit. Check it with hermes --version.

A one-line installer that downloads a prebuilt, sha256-verified bundle is in progress. It goes on this page once a release ships the bundles it expects and we have tested it. The upstream installer at hermes-agent.nousresearch.com installs upstream Hermes, not Talos.

CLUD

Claude & Codex CLI, with safety 3rd and God Mode always.

talos-hq/clud

curl -fsSL https://raw.githubusercontent.com/talos-hq/clud/main/install.sh | sh

What it does

  • Installs uv with Astral's installer if it is not already on your PATH.
  • Runs uv tool install clud, which puts one clud executable in uv's tool directory, then self-checks it.
  • Updates your shell PATH. Set CLUD_NO_PATH=1 to leave your shell profile alone.

Prerequisites

  • A POSIX shell and curl. uv is installed for you if it's missing.

Pin a version

curl -fsSL https://raw.githubusercontent.com/talos-hq/clud/main/install.sh | CLUD_VERSION=2.8.47 sh

Check it with clud --version. Releases: manifest.json.
