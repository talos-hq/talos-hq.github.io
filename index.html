Install Talos.
One command.

curl -fsSL https://talosbot.ai/install.sh | sh
irm https://talosbot.ai/install.ps1 | iex

Paste it into a terminal. You get a signed, sha256-verified bundle with Python included, and nothing to compile. Then add one key and Talos is running.

From zero to running

Installed and deployed in three steps

  1. Run the command

    The installer detects your OS and CPU, downloads the matching bundle, checks its sha256, and puts hermes on your PATH.

  2. Add your key

    Setup starts by itself and asks for an OpenRouter key in a masked prompt. The key is stored in your profile and never shown to the model.

  3. It's live

    Setup starts the gateway as a background service. Run hermes to chat in the terminal, or message your bot.
