Talos HQ

TALOS

Plan. Reason. Build.

A personal agent that runs in your terminal and on your messaging apps. It is built on Hermes Agent, ships with our fixes, and keeps pulling in every fix from upstream.

Install Talos Source

  1. Hermes at the core

    Talos runs Hermes Agent from Nous Research: the same CLI, messaging gateway, memory and skills.

  2. Fixes built in

    We fix what breaks for us in the installer, the state store and the gateway, and ship those fixes now.

  3. Upstream, always

    Upstream main is merged into Talos continually, so nothing the Hermes project fixes is left behind.

What it does

An agent that does the work

Talos keeps the parts of Hermes that make it useful day to day, and we work on making it install and run reliably.

Plans and delegates

It breaks work into steps and hands pieces to subagents.

Real tools

It runs a real terminal and browser, not a simulation of one.

Memory and skills

It remembers across sessions and learns skills, so it grows with you.

Wherever you are

Use it from the CLI or TUI, or message it on Telegram and other platforms through the gateway.

Scheduled jobs

It runs recurring work on a schedule without you starting it.

Tracks upstream

Fixes from Nous Research flow in through regular upstream syncs.
